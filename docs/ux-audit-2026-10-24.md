# UX-аудит по референсам — 24.10.2026

Смотрел на телефоне (375 px): me&u (живое меню Monsoons, meandu.app), Toast (order.toasttab.com/online/super-nice-pizza), Speiso (speiso.com/karte/zwei-welten-restaurant), сайты MENU TIGER и FineDine (только описания функций, живых демо нет). Наше: /belvedere (classic), /demo/carta (три вида), код админки /app.

| me&u | Липкая строка разделов + поиск + фильтр сверху; при многих разделах — выпадающий список всех разделов. |

| все | Ничего не «проваливается»: страница открывается без спиннеров, первый экран — сразу меню. |

## Что берём (решено, делаю сейчас)

Гость:
1. Каждое блюдо открывается карточкой (сейчас — только если есть фото/аллергены/текст).
2. Кнопка «Разделы»: лист со всеми разделами и числом блюд, когда разделов ≥ 5 (как выпадающий список me&u).
3. Кнопка «Aa» — крупный текст для гостя (запоминается на телефоне).
4. Читаемость: описания 15 px вместо 14, контраст серого текста выше, миниатюры 84–88 px.
5. Языки: при 5+ языках — лист выбора с названиями на самом языке (делается в шаге «Языки»).

Админка (шаг 4):
1. Нижняя панель вкладок на телефоне: Übersicht · Speisekarte · Tische · Service · Mehr.
2. Редактор меню: разделы сворачиваются, поиск по блюдам при > 30 позиций, порядок блюд стрелками прямо в списке.
3. Обзор: «сегодня» — быстрые переключатели «распродано» и кнопка «Ansehen» на телефоне.

Не берём: заказ и оплата со стола (решение владельца), ИИ-импорт из фото (без платного ИИ), программы лояльности.

## Замечания по нашему текущему состоянию

- Гостевое меню: карточка не открывается у блюд без деталей — гость не понимает, почему одно открывается, другое нет.
- Строка языков: пилюли DE/EN/IT/UA; при 20+ языках не влезет.
- Админка: 10 вкладок горизонтальной прокруткой, на телефоне половина не видна.
- Снимки админки под входом владельца не делал (нет локального входа); проверено по коду.
